# CS330 OpenGL 3D Scene

A 3D graphics project developed for SNHU's CS-330: Computational Graphics and Visualization course using C++ and OpenGL.

The project focused on recreating a reference photograph as a 3D scene using primitive shapes, custom meshes, textures, lighting, and camera controls.

## Project Overview

For this project, I recreated a reference scene by breaking the objects in the photograph down into simpler 3D components. I created meshes from primitive shapes and used textures, shading, and lighting to make the scene resemble the original reference.

### Features

* 3D scene created with C++ and OpenGL
* Custom camera movement and controls
* Lighting and shading
* 3D objects constructed from primitive shapes
* Textures applied to scene objects
* Multiple 3D objects combined to recreate a reference scene

## Design Process

I approached the scene by first identifying the major objects in the reference photograph and breaking them down into simplified components.

My general process was:

1. Analyze the reference photograph.
2. Break complex objects into simpler primitive shapes.
3. Create meshes from those shapes.
4. Position and scale the objects to match the reference.
5. Apply textures and shading.
6. Add lighting to improve the appearance of the scene.
7. Adjust the camera and scene composition.

Breaking complex designs into smaller components is a technique I can apply to future software and game development projects.

## Development Process

Iteration was an important part of developing this project. The project was divided into milestones so I could focus on individual parts of the scene instead of trying to build everything at once.

I also used [LearnOpenGL](https://learnopengl.com/) as a learning resource to better understand OpenGL concepts and the techniques needed to create the scene.
